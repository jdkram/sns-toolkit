Access levels

{% include "bs_messages.html" %}

This page explains what each access level can do and shows who currently holds elevated access. It is visible to all logged-in users to support collective accountability and transparency.

{# ── Rights table ──────────────────────────────────────────────────────────── #}

What each access level can do

Tier Who What they can do
Volunteer All logged-in volunteers View the programme and rota. Sign up for and remove themselves from rota slots. Edit their own volunteer profile (name, pronouns, access rider, contact details). View the volunteer directory. View internal event information (rota notes, links).
Programmer Members granted programming access by a Panopticon user Everything Volunteers can do, plus: create, edit, and delete events and showings. Manage rota entries for any volunteer. View the full volunteer list and summaries. Use and manage event templates, tags, and roles. Access the programming calendar and diary editing tools. Cannot access volunteer or member personal data (names are visible on the rota but full PII (emails, phone numbers, addresses, access riders) requires Panopticon access).
Panopticon Members granted full toolkit access by another Panopticon user Everything Programmers can do, plus: view and edit all volunteer and member personal information (names, email addresses, phone numbers, postal addresses, access riders, emergency contacts). Perform GDPR right-to-erasure (anonymisation) of volunteer records. Grant or revoke Programmer and Panopticon access for other users. Manage site configuration settings. Manage user accounts (username, login access, password resets). Panopticon users can see all personal data held in this system. This access should be held by the minimum number of people necessary.
