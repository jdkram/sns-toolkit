Every email the toolkit has attempted to send, from any feature. "Sent" means the configured email backend accepted the message, not that it reached an inbox. Bodies are not stored; mailouts appear as one summary row per batch.

What "the configured email backend" means: it's the piece of software actually responsible for handing your message to the outside world. Right now that's set to {{ configured_backend }}, which in plain terms means: {{ configured_backend_description }} A row marked "Sent" below only means the toolkit handed the message to this backend without error. If the backend is the console or file backend, nothing left the server at all; if it's SMTP, the message reached a mail server, which is still no guarantee it reached the recipient's inbox. The toolkit does not currently detect bounces (e.g. a dead or full mailbox) after that point; see docs/tasks/ for the proposed bounce-handling feature.
