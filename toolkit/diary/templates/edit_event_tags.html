Event Tags

Tags describe events (e.g. "Live Music", "Performance"). Filter groups are the small set of broad categories shown as filter buttons at the top of the public programme page, each one bundling several tags together (e.g. "Live Music" and "Performance" might both map to a "Music" filter group), so visitors see a few simple choices instead of every tag.
