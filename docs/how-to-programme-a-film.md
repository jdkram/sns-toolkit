# How to programme a film at Star and Shadow

This guide walks a volunteer programmer through proposing, licensing, and running a film or TV screening, end to end. It supersedes nothing: the authoritative source is the *Film and Television Programming Guide* on NextCloud (last updated January 2025); this page extracts the parts that matter for using the Toolkit and dealing with distributors and TicketSource.

For what the software itself enforces around film events (seasons, the reserved screening slot, the summary length, and the Toolkit fields), see [SPEC.md §4.5](SPEC.md#45-film-programming-in-toolkit).

## Propose a screening

Submit your idea via the Film Programming Suggestions form before the season's deadline. Each proposal needs a **25-word summary or pitch**: this exact wording goes into the print programme and to *The Crack* and *NARC* magazines, so write it as you want it published. If you need to change it after submission, ask the Social Media Team at least two weeks before the end of the month.

## Find a distributor

Start with Filmbank: it's cheaper and simpler than the alternatives and covers a broad catalogue. If Filmbank doesn't have your film, the [Independent Cinema Office](https://www.independentcinema.org) site lists UK distributors. Commonly used ones besides Filmbank: Park Circus, BFI, Janus, Curzon, Arrow Films, Second Run, Altitude, Contemporary Films, Cineuropa, Bulldog, Cult Films, Dogwoof, Eureka, Film4, ICA, Lux, Modern Films, Vertigo. Still stuck? Ask the Film Programming Group.

## Get it through the Programming Group

The group meets twice a season.

**First meeting:** you present your proposal. If it's taken forward, distributor contacts reach out to confirm availability, usually within 24 hours (Filmbank licences don't need this step). One person is elected to handle requests to the main Programming Group on the schedule's behalf.

**Second meeting:** the provisional schedule is reviewed, alternatives discussed if a licence fell through, and last-minute additions considered.

## Book the licence

**If it's a Filmbank title**, book it yourself via the S&S Filmbank account: New booking → Indoor → yes to ticket price → title, date, number of showings. Do this before the third and final Film Programming Group meeting, usually 2–3 weeks after the second.

**For any other distributor**, your distributor contact handles the booking and confirms once it's done.

If a screener is required and you have no preference on format, buying a DVD/Blu-ray yourself and claiming the cost back is usually faster and cheaper than waiting for one to be sent. Arranging delivery is your responsibility. So is returning it afterwards, using the same courier as the delivery: distributors remember who sends screeners back promptly.

## Add the event to Toolkit

You'll need Programmer rights (ask for these at a Film Programming Group meeting if you don't already have them). Fill in:

| Field | Notes |
|---|---|
| Room | Cinema |
| Start | Usually 19:30 on the screening date |
| Event name | Film or TV show title |
| Event template | Choose the closest format to your screener |
| Pricing | Typically £7/£5/£3/£0 (Full / Concessions / Further concessions / Free) |
| Ticket link | Add once TicketSource is set up (below) — you can return to the diary entry any time |
| Film information | Dir. (Director), Year, Country, Runtime (mins), BBFC rating |
| Programmer's notes | Private, visible to volunteers only |
| Copy | Public-facing description |
| Terms | Distributor name and licence fee |
| Image | Use a distributor-provided image; the Filmbank account gives you access to film poster scans. Don't use Google Images — copyright risk. |

Once the TicketSource link is in, mark the showing **Confirmed** to put it live.

## Set up TicketSource

1. Create a new event with the same details as your Toolkit entry.
2. **Add venue**: search "Star and Shadow" and choose the first result; it autocompletes the address.
3. **Add date**: set date and time. No doors or end time needed. Set "Stop ticket sales" to **1 hour before start time**.
4. **Add ticket allocation**: choose "Tickets are allocated on a seating plan" → select **"2025 Seating Plan"** → uncheck "Enable orphan seat rule on internet bookings".
5. **Add pricing categories**: Full price, Concessions, Further concessions, Gratis/Free. For the Free tier, enable "Individual ticket" and set maximum selection to 1.
6. **Activate** the event, then **Publicise**, then copy the Ticket shop URL into your Toolkit diary entry. A QR code is also available if you want one for print promotion.

Ticket sales close 1 hour before the showing starts. Print the TicketSource sales sheet and make sure the Box Office volunteer has it, along with the seating plan.

## On the day

- Arrive second, after the Keyholder, at least 1 hour before start.
- The Projectionist sets up the screener; make sure they have it in hand. If your Toolkit has film readiness switched on, the Event Hub's **Film readiness** panel is where you record that the film has arrived and been test-played, and leave a note for the projectionist.
- The Projectionist will check with you about sound and aspect ratio.
- You can give a short introduction if you want to (not mandatory) — a good moment to plug upcoming events.
- Help the Keyholder close up afterwards.
- Don't sign up for other rota roles on top of this one: coordinating the screening is the job.

## Promote it

- Your 25-word summary goes to *The Crack* and *NARC* via the Social Media Team.
- The team covers Facebook, Instagram, BlueSky, Threads, and X. Facebook Events is the primary engagement channel.
- A weekly round-up of the next seven days' events goes out on all channels.
- Want more promotion? Ask the Social Media Team for an additional post (subject to space in the content schedule), or use your own networks.
